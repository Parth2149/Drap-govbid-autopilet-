# nebiusXnvidia

## Project Structure

- `frontend/` - Angular workspace / frontend application
- `n8n-workflows/` - Exported JSON files of n8n automation pipelines
- `supabase/` - Database schemas, edge functions, and vector store configurations
- `nebius-endpoints/` - Scripts and API payloads for Nebius Token Factory calls
- `docs/` - Architecture diagrams and documentation
